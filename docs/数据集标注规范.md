# 数据集标注规范

## 目录结构

```text
datasets/traffic/
  data.yaml
  images/
    train/
    val/
    test/
  labels/
    train/
    val/
    test/
```

图片和标签文件同名，例如：

```text
images/train/road_001.jpg
labels/train/road_001.txt
```

## 标签格式

采用 YOLO 标注格式：

```text
class_id center_x center_y width height
```

坐标均为 0-1 之间的归一化值。

## 类别定义

| id | 类别 |
| --- | --- |
| 0 | person |
| 1 | bicycle |
| 2 | car |
| 3 | motorcycle |
| 4 | bus |
| 5 | truck |
| 6 | traffic light |
| 7 | stop sign |
| 8 | fire hydrant |

## 采集建议

1. 每类至少 300-500 个有效目标框，车辆和行人应更多。
2. 每个场景都要保留原始视频或图片来源说明。
3. 包含多天气、多时段、多角度、多遮挡样本。
4. 车牌、人脸等敏感信息应尽量模糊或选择不可识别素材。
5. 训练集、验证集、测试集不要来自同一段连续视频的相邻帧，避免指标虚高。
