# 智能交通检测系统 - 项目说明

完整部署、启动、训练、评估和答辩流程见：`docs/项目完整部署与使用手册.md`。

## 🌟 五大创新点

### 1️⃣ 多目标实时跟踪技术
- 采用IOU匹配算法实现车辆ID跟踪
- 支持多车辆同时跟踪，轨迹可视化
- 解决遮挡、交叉等复杂场景

### 2️⃣ AI运动状态与标定车速
- 未标定时不输出不可信 km/h，改用AI运动指数展示静止/缓行/行驶/快速
- 支持配置 `meters_per_pixel` 后切换为真实车速趋势
- 结合光流背景补偿，降低静止车辆误判为运动的概率

### 3️⃣ 本车主体状态判断
- 适配行车记录仪和车载拍摄场景
- 判断本车静止、缓动、行驶、转向、颠簸
- 风险判断不再单纯依赖目标位移

### 4️⃣ 行人视角避险
- 行人视角识别危险来车
- 给出左侧来车、右侧来车、正前方来车等方向判断
- 输出向左避让、向右避让、暂停观察/后退等建议

### 5️⃣ 智能检测报告生成
- 一键生成JSON格式检测报告
- 包含时间戳、统计数据、危险记录
- 支持数据导出和后续分析

### 1. 上传视频
点击"📤 上传视频"按钮，选择本地视频文件（支持mp4/avi/mov/mkv）

### 2. 摄像头实时检测
点击"🎥 实时摄像头"按钮，系统会打开默认摄像头并实时进行目标识别、跟踪、估速和风险预警。

如需更换摄像头编号，可修改 `configs/traffic_config.json` 中的 `input.camera_index`。

### 3. 开始检测
点击"▶️ 开始检测"，系统将自动：
- 识别视频中的车辆和行人
- 跟踪每辆车的运动轨迹
- 估算车速
- 检测危险情况

### 4. 观察结果
- **左侧**: 实时检测画面，带跟踪ID和车速
- **右上**: 实时统计数据
- **右中**: 危险预警日志
- **右下**: 车速趋势图

### 5. 生成报告
点击"📄 生成报告"导出检测数据

## 🔧 国赛升级版说明

当前版本已加入以下工程化改造：

- 使用 `configs/traffic_config.json` 统一配置模型路径、检测阈值、跟踪阈值、限速阈值和预警冷却时间。
- 支持本地视频文件和摄像头实时输入两种模式。
- 跟踪逻辑由单纯中心点距离匹配升级为 IOU 优先匹配，降低 ID 跳变。
- 速度估计加入异常速度过滤和速度跳变抑制，避免报告中出现明显不可信的车速。
- 危险预警加入事件冷却机制，避免同一目标逐帧重复刷屏。
- 报告增加模型路径、速度阈值、焦距参数、异常速度过滤次数等可答辩参数。
- 界面新增累计目标统计、实时 FPS、画面数据条和中/高风险等级显示。
- 目标框中文标签改用 PIL 字体绘制，避免中文显示成问号。
- 速度估计新增中心点平滑、位移死区和静止速度阈值，降低停车车辆误报速度。
- 新增 AI 光流运动分析，未配置像素尺度标定时显示“静止/缓行/行驶/快速”和 AI 速度指数；完成 `camera.meters_per_pixel` 标定后再输出 km/h。
- 新增本车主体状态估计，可判断车载录制时本车静止、行驶、转向或颠簸，并进行背景运动补偿。
- 新增行人横穿风险评估，可结合横穿区域、行人横向运动、附近车辆和本车运动状态判断风险等级。
- 新增行人视角避险模式，可从行人端摄像头判断左侧/右侧/正前方危险来车，并给出避让建议。
- 新增道路 ROI、类别阈值、小框过滤和稳定目标确认，减少非道路区域误检。
- 新增训练入口 `scripts/train_traffic.py` 和评估入口 `scripts/evaluate_traffic.py`，用于后续自建交通数据集训练。

### 训练自定义交通模型

整理数据到 `datasets/traffic/` 后运行：

```bash
python scripts/train_traffic.py --data datasets/traffic/data.yaml --model yolov8n.pt --epochs 80 --imgsz 640
```

评估模型：

```bash
python scripts/evaluate_traffic.py --weights runs/traffic/yolov8n_traffic/weights/best.pt
```

训练完成后，将 `configs/traffic_config.json` 中的 `model_path` 改为训练得到的 `best.pt`。
