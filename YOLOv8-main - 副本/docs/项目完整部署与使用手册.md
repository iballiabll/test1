# 路眼：智能交通检测系统完整部署与使用手册

版本日期：2026-05-07

## 1. 项目定位

本项目面向全国人工智能创新赛演示场景，主题保持为“道路交通目标识别与风险预警”。系统基于 YOLOv8 完成车辆、行人和道路标志目标检测，并叠加多目标跟踪、AI 运动状态分析、本车主体状态判断、行人视角避险、横穿风险预警、检测结果保存和自动报告生成。

核心目标不是只做一个目标检测 demo，而是形成一个可讲清楚技术路线、可现场演示、可生成结果材料的完整智能交通感知系统。

## 2. 当前功能清单

| 模块 | 功能 |
| --- | --- |
| 输入源 | 本地视频上传、摄像头实时输入 |
| 目标检测 | person、car、truck、bus、motorcycle、bicycle、traffic light、stop sign、fire hydrant |
| 多目标跟踪 | IOU 优先匹配、中心距离兜底、轨迹平滑、稳定目标确认 |
| AI 运动分析 | 光流分析、背景运动补偿、静止/缓行/行驶/快速状态判断 |
| 本车状态 | 判断本车静止、缓动、行驶、转向、颠簸，适配行车记录视角 |
| 速度显示 | 未标定时显示 AI 运动指数，完成标定后显示 km/h |
| 行人避险 | 行人视角识别危险来车方向，输出避让建议 |
| 横穿风险 | 车辆视角判断行人横穿风险 |
| UI 展示 | 综合展示、车辆感知、行人避险三种演示模式 |
| 结果保存 | 输出检测视频、自动截图、手动截图、JSON/TXT 报告 |
| 工程化 | 配置文件、训练脚本、评估脚本、环境验证脚本、一键部署和一键启动脚本 |

## 4. 环境要求

推荐环境：

| 项目 | 推荐配置 |
| --- | --- |
| 操作系统 | Windows 10/11 |
| Python | 3.10 或更高版本 |
| CPU | Intel i5 / AMD Ryzen 5 及以上 |
| 内存 | 8 GB 及以上 |
| GPU | 可选，NVIDIA GPU + CUDA 可提升推理速度 |
| 摄像头 | 可选，USB 摄像头或笔记本内置摄像头 |

说明：

- CPU 环境可以运行演示，但实时 FPS 会受机器性能影响。
- GPU 环境建议按 CUDA 版本单独安装对应 PyTorch，再运行项目依赖安装。
- 当前项目自带 `yolov8n.pt`，无网络时也能加载默认模型。

## 5. 一键部署流程

第一次使用时，在项目根目录双击：

```text
一键部署环境.bat
```

如果比赛机对中文文件名支持不好，双击：

```text
setup_env.bat
```

脚本会自动执行：

1. 检查 Python 是否可用。
2. 创建项目虚拟环境 `.venv`。
3. 升级 `pip`、`setuptools`、`wheel`。
4. 安装 `requirements.txt` 中的依赖。
5. 运行 `scripts/verify_environment.py --load-model` 验证包、配置、模型、Tkinter 和 YOLO 权重。

部署成功后会看到“环境部署完成”。

## 6. 一键启动流程

部署完成后，在项目根目录双击：

```text
一键启动系统.bat
```

或使用英文入口：

```text
start_app.bat
```

启动脚本会：

1. 优先使用 `.venv` 中的 Python。
2. 快速验证依赖和项目资产。
3. 如果环境不完整，自动调用一键部署脚本修复环境。
4. 启动 `智能交通检测系统_比赛版.py`。

旧入口 `比赛启动.bat` 已保留，会转到新版一键启动脚本。

## 8. 基本使用流程

### 8.1 本地视频检测

1. 点击 `上传视频`。
2. 选择 `mp4`、`avi`、`mov` 或 `mkv` 文件。
3. 点击 `开始检测`。
4. 观察左侧检测画面和右侧数据面板。
5. 检测结束后点击 `生成报告`。

### 8.2 摄像头实时检测

1. 点击 `实时摄像头`。
2. 系统会打开 `configs/traffic_config.json` 中的 `input.camera_index`。
3. 检测过程中可切换 `综合展示`、`车辆感知`、`行人避险` 模式。
4. 点击 `停止` 结束检测。
5. 点击 `生成报告` 输出材料。

如默认摄像头打不开，修改：

```json
"input": {
  "camera_index": 0,
  "camera_width": 1280,
  "camera_height": 720
}
```

常见摄像头编号为 `0`、`1`、`2`。

右侧面板分为三类指标：

| 区域 | 适合讲解 |
| --- | --- |
| 车辆感知 | 车辆数量、累计跟踪、本车状态、AI 速度指数、静止车辆、稳定目标 |
| 行人避险 | 累计行人、危险来车、横穿风险、危险次数 |
| 系统状态 | 路障、智能过滤、实时 FPS |

演示模式：

| 模式 | 说明 |
| --- | --- |
| 综合展示 | 同时展示车辆、行人和风险信息 |
| 车辆感知 | 突出车辆检测、本车状态和运动指数 |
| 行人避险 | 突出行人视角危险来车、方向和避让建议 |

左侧视频区域采用“保持比例并铺满显示”，不会拉伸变形。为了避免空白边，边缘可能会被轻微裁切。

## 10. 配置文件说明

配置文件路径：

```text
configs/traffic_config.json
```

常用配置：

| 字段 | 说明 |
| --- | --- |
| `model_path` | YOLO 权重路径 |
| `confidence` | 默认检测置信度 |
| `input.camera_index` | 摄像头编号 |
| `tracking.min_confirmed_hits` | 连续确认帧数，越大越稳但响应更慢 |
| `detection.class_thresholds` | 各类别检测阈值 |
| `roi.enabled` | 是否启用道路 ROI 过滤 |
| `camera.meters_per_pixel` | 速度标定参数 |
| `speed.require_calibration` | 是否要求标定后才显示 km/h |
| `motion_ai.*` | AI 运动分析阈值 |
| `crossing_risk.*` | 行人横穿风险规则 |
| `pedestrian_safety.*` | 行人视角避险规则 |

## 11. 速度与标定说明

系统默认不显示未经标定的真实车速，避免把视频像素位移误当成真实 km/h。

未标定时：

- 车辆标签显示 `AI:静止/缓行/行驶/快速`。
- 右侧趋势图显示 `AI index`。
- 报告中车速字段显示 `待标定`。

完成标定后：

- 在 `configs/traffic_config.json` 中设置：

```json
"camera": {
  "focal_length": 800,
  "meters_per_pixel": 0.05
}
```

- 系统自动切换为 `km/h` 车速趋势。

标定建议：

1. 找一段固定机位视频。
2. 选取路面上真实长度已知的线段，例如 3 米车道线或 10 米路段。
3. 计算 `meters_per_pixel = 真实长度米数 / 图像像素长度`。
4. 写入配置文件。

行车记录仪视角下，速度估计更依赖本车状态补偿和 AI 运动指数，不建议强行宣称精确 km/h。

## 13. 模型训练

训练命令：

```bat
.venv\Scripts\python.exe scripts\train_traffic.py --data datasets/traffic/data.yaml --model yolov8n.pt --epochs 80 --imgsz 640 --batch 16
```

CPU 训练：

```bat
.venv\Scripts\python.exe scripts\train_traffic.py --device cpu --batch 4
```

GPU 训练：

```bat
.venv\Scripts\python.exe scripts\train_traffic.py --device 0 --batch 16
```

训练输出默认在：

```text
runs/traffic/yolov8n_traffic/
```

训练完成后可将最优权重复制或配置为：

```json
"model_path": "runs/traffic/yolov8n_traffic/weights/best.pt"
```

## 14. 模型评估

评估命令：

```bat
.venv\Scripts\python.exe scripts\evaluate_traffic.py --weights runs/traffic/yolov8n_traffic/weights/best.pt --data datasets/traffic/data.yaml
```

评估结果会输出并保存到：

```text
检测结果/evaluation_metrics.json
```

关键指标：

| 指标 | 说明 |
| --- | --- |
| `box_map50` | IoU 0.5 下的 mAP |
| `box_map50_95` | COCO 风格 mAP |
| `precision` | 精确率 |
| `recall` | 召回率 |

## 16. 比赛演示建议

推荐 5 分钟演示结构：

1. 项目背景：道路安全、行人避险、智能交通感知。
2. 技术路线：YOLOv8 检测、多目标跟踪、光流运动分析、风险规则。
3. 综合展示：上传视频，展示检测框、轨迹、统计面板。
4. 车辆感知模式：讲本车状态、静止车辆识别、AI 速度指数。
5. 行人避险模式：讲危险来车方向、避让建议、横穿风险。
6. 结果输出：生成报告，展示 JSON/TXT 记录。
7. 可扩展性：训练自有数据集、标定真实速度、接入摄像头。

推荐素材：

- 固定机位道路视频，用于展示横穿风险和车辆稳定跟踪。
- 行车记录仪视角视频，用于展示本车主体状态判断。
- 行人视角视频，用于展示危险来车和避让建议。
- 包含交通灯、停车标志的道路视频，用于展示多类别识别。

## 17. 常见问题

### 17.1 启动时报缺少依赖

运行：

```text
一键部署环境.bat
```

或：

```bat
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 17.2 摄像头打不开

修改 `configs/traffic_config.json`：

```json
"camera_index": 1
```

然后重新启动系统。

### 17.3 速度显示待标定

这是正常设计。未设置 `meters_per_pixel` 时，系统不会输出未经标定的 km/h，而是显示 AI 运动指数。

### 17.4 静止车辆被误判运动

优先检查：

- 视频是否来自移动中的车辆。
- `motion_ai.ego_stationary_px` 和 `motion_ai.ego_driving_px` 是否适合当前视频。
- 是否有强抖动或大面积运动背景。

本系统已经加入本车主体状态判断和背景补偿，但低画质、夜间、强抖动视频仍可能影响光流质量。

### 17.5 右侧面板被挤没

已修复。右侧面板固定宽度，左侧视频显示不会再反向撑大布局。

### 17.6 图表没有速度曲线

未标定时图表显示 `AI index`；完成 `meters_per_pixel` 标定后自动切换到 `km/h`。

### 17.7 输出视频打不开

可能是 OpenCV 编码器不可用。系统会继续显示画面和截图，并在风险日志提示视频写入失败。建议更换电脑或安装完整 OpenCV 环境。

## 19. 后续优化方向

如继续增强国赛竞争力，建议按优先级推进：

1. 使用自采道路数据微调模型，提升小目标和夜间识别。
2. 增加速度标定界面，允许用户在图像上点选已知长度。
3. 引入更强跟踪器，例如 ByteTrack / BoT-SORT。
4. 增加风险评分可解释面板，把风险原因结构化展示。
5. 做轻量 Web 或大屏展示版，方便答辩投屏。
6. 增加测试集评估报告，形成可量化比赛材料。
